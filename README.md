# Twitch Emotes

Запуск: `npm start`, затем http://localhost:5173.

Одна вкладка, только статичные реакции. Две открытые ладони показывают Absolute Cinema. Кулак, большой палец и указание влево/вправо пока показывают обычные эмодзи. DEFAULT показывает normal.jpg после запуска камеры. До запуска и после остановки поле пустое. Анимации и распознавание движения отключены.

Для замены эмодзи на изображения добавь путь для нужного жеста в gestureImages в src/display.js. Сейчас настоящие Twitch emotes для этих жестов еще не добавлены.

src/camera.js — камера; recognition.js — MediaPipe для двух рук; gestures.js — простые жесты; state.js — стабилизация; display.js — картинки и каркас рук; main.js — управление. `npm test` запускает проверки. Видео обрабатывается локально, интернет нужен для загрузки модели.

Лицо: src/face.js загружает FaceLandmarker и рисует голубые контуры глаз, бровей, губ и лица. Руки остаются зелеными. Мимика пока не управляет реакциями. Обработка локальная, при ошибке модели лица руки продолжают работать.

Лицо, руки и поза тела отслеживаются без отображения контуров. src/pose.js использует облегченную модель PoseLandmarker. Для отслеживания ног и стоп пользователь должен целиком попадать в кадр. Реакции пока управляются только жестами рук.

Контуры скрыты. Лицо, руки и поза продолжают отслеживаться.

POINT_CAMERA: направь указательный палец в объектив рукой в левой половине отображаемого видео, остальные три пальца согни. Включается point-camera.gif. Используются сгибы и глубина landmarks; при перекрытии пальцев точность может снижаться.

Сторона кадра для POINT_CAMERA учитывает CSS-зеркалирование видео. Указание допускается под углом, точное направление в объектив не требуется.

SHAKA: большой палец и мизинец раскрыты, остальные согнуты. Рука должна быть слева в отображаемом видео. Показывается shaka.png, пока жест распознается.

Изображения занимают всю ширину правой панели. Высота определяется пропорциями файла, поэтому вертикальные мемы выше видео. Изображения не обрезаются и не искажаются.

Область реакции зафиксирована в пропорции 4:3, как видео. Изображения заполняют ее без искажений через object-fit: cover, края при необходимости обрезаются.

Обе области теперь квадратные, 1:1. GIF и картинки помещаются целиком через object-fit: contain; для неквадратных файлов остаются поля.
